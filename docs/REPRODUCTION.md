# 复现流程

本文件用于帮助后来者从 GitHub 仓库复现硬件工程。

## 环境

- 立创 EDA 专业版。
- 能够查看或导出原理图、PCB、Gerber、BOM 的本地环境。
- 具备飞控、电源、IMU、气压计、OSD、存储和多旋翼整机调试经验的测试条件。

## 步骤

1. 克隆或下载仓库。
2. 在立创 EDA 专业版中打开 `ProPrj_v307飞控_2026-08-23.epro2`。
3. 检查工程中的原理图、PCB、网络连接、封装和丝印。
4. 根据 README 中的硬件构成核对 CH32V307、CH549G、ICM42688、MPU6050、DPS310、AT7456E、W28Q128 和电源路径。
5. 导出 Gerber、钻孔、BOM 和坐标文件，并与打样平台要求核对。
6. 样板回来后先做不上电目检，再用限流电源逐级验证 3.3V、5V、主控下载、传感器、存储、OSD 和外设接口。

## 记录建议

- 记录打样日期、PCB 版本、关键器件批次和异常现象。
- 对整机调试记录输入电压、外设连接、传感器状态、飞行时间、日志和异常情况。
- 复现过程中发现的问题建议用 Issue 公开记录，便于后续追踪。
