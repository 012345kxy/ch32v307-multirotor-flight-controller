# 安全检查清单

本项目面向多旋翼飞控和整机调试，测试时请优先保证飞行安全和人员安全。

## 上电前

- 检查电池输入、稳压输出、传感器供电、外设接口和下载接口。
- 确认 3.3V、5V、IMU、气压计、存储、OSD 和主控周边没有短路。
- 初次上电使用限流电源，不直接连接动力电池和电调。
- 接入电调或电机前先拆桨，并确认信号线、地线和供电路径。

## 调试中

- 先做桌面传感器、遥控、OSD、日志和参数调试，再进入动力系统测试。
- 动力测试必须拆桨，飞行测试必须选择空旷场地并设置失控保护。
- 传感器异常、姿态跳变、电源跌落或参数不确定时不要起飞。
- 固件或硬件修改后，重新执行静态校准和低风险地面测试。

## 发布前

- 在 README 或 Issue 中公开已验证的供电范围、接口状态、传感器状态和飞行测试边界。
- 未验证的飞行性能、可靠性或兼容性不要写成承诺值。
- 与飞行安全相关的缺陷应优先修复或明确标注为已知问题。
