# Assessment Evidence Checklist

Project: CH32V307 Multirotor Flight Controller

This checklist helps collect evidence for open-source contribution assessment.

## Public Repository Evidence

- Repository homepage URL.
- Public visibility screenshot.
- Commit history screenshot showing English source-code commits.
- Release page screenshot if a release is referenced.
- README screenshot showing project value, license, photos, and source-code entry.

## Technical Completeness Evidence

- Hardware project file in the repository root.
- CERN-OHL-P-2.0 license file.
- Device photos in photo/.
- Source-code archive in code/.
- Documentation files under docs/, especially SOURCE_CODE.md, SOURCE_MANIFEST.md, and OPEN_SOURCE_EVIDENCE.md.
